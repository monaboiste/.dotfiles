# Global Agent Instructions

- Use concise, direct language. Prefer concrete instructions over general explanations. Follow ASD-STE100 Simplified
  Technical English principles where practical.
- If a command, code change, or configuration change solves the problem, show it before a longer explanation.
- Never use the em dash ("—"). Use a regular hyphen ("-") instead.
- Unless explicitly requested, do not add explanatory comments or divider comments (for example, `// --- Helpers ---`)
  when writing code. This comment rule does not apply to the `ponytail` project.
- Always spawn delegated agents through Herdr. Never use direct subagent processes.
